Claude web, desktop e mobile

Recomendado: é a instalação mais simples e ativa a base completa do Leadership MCP.

1. Copie sua URL

Esta URL é o endereço técnico do conector — ela não é uma página para abrir diretamente no navegador. Copie-a e cole nas configurações do Claude.

2. Abra os conectores do Claude

  1. Abra Configurações no Claude.
  2. Entre em Conectores.
  3. Clique em Adicionar conector personalizado.
  4. Cole a URL acima e confirme.
Abrir configurações do Claude

Depois, em uma conversa, abra + → Conectores e ative o Leadership MCP.

Claude Desktop local

Use esta opção se você quer que o servidor rode na sua própria máquina, sem usar o conector web.

1. Instale o Claude Desktop

Baixe o aplicativo oficial e abra Configurações → Desenvolvedor → Editar configuração.

2. Cole esta configuração

{ "mcpServers": { "leadership": { "command": "npx", "args": ["-y", "leadership-mcp"] } } }

3. Reinicie o Claude Desktop

Depois, abra uma conversa e peça ajuda com uma situação difícil.

Como testar

Depois de instalar no Claude, escreva algo como:

O Claude deve perceber que existe uma situação relacional e oferecer a consulta ao Leadership MCP antes de responder.
